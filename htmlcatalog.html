<base>

Lihat project pertama
  • base (href) digunakan untuk menetapkan root directory satu halaman ini sehingga tiap anchor akan jadi turunan dari direktori base. Penulisan direktori base dimulai dari setelah nama Domain. Base harus ada sebelum atribut apapun yang punya url
  • base (target) (_self[default]) tampilkan link sebagai pengganti/browsing-context halaman ini
  • base (target) (_blank) tampilkan link di tab baru
  • base (target) (_parent) tampilkan link di parent frame
  • base (target) (_top) tampilkan link di parent tertinggi
